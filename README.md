# Odin Recipes
Projet : Recettes
Ce projet est réalisé dans le cadre du parcours The Odin Project. Il consiste à créer un site web basique de recettes pour mettre en pratique les notions fondamentales de HTML.

## Compétences démontrées
- Structuration de pages web avec HTML (titres, paragraphes, listes, images)
- Navigation entre différentes pages via des liens hypertexte
- Gestion de version et suivi du projet avec Git et GitHub
